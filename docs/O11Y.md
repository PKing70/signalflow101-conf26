# Splunk Observability Cloud Setup

Use Splunk Observability Cloud in your browser to view the shared workshop
dashboard and confirm that your Python metrics are arriving.

Your O11y sign-in is separate from Replit, GitHub, and Splunk Show. Your Python
environment sends metrics; O11y is where you view them.

## Sign In

1. Open the Splunk Observability Cloud workshop link from your handout, or open:

```text
https://app.us1.observability.splunkcloud.com/
```

2. Sign in with the O11y workshop account instructions from your handout.

The handout points you to the O11y workshop. It does not print token values.
Do not put O11y passwords or token values in chat tools, screenshots, Python
files, or the public repo.

If O11y asks you to choose an organization, choose **Observability Workshop
AMER**. If O11y asks you to choose a team, choose
**DEV1942-signalflow101**.

## Open The Workshop Dashboard

1. Open **Dashboards**.
2. Search for `SignalFlow`.
3. Under **Custom dashboard groups**, open **SignalFlow 101 - .conf26**.
4. Open **SignalFlow 101 - Workshop Fleet**.

You can also use the direct dashboard URL:

```text
https://app.us1.observability.splunkcloud.com/#/dashboard/HPtrGG-A4AE?groupId=HPtqyd5A0AA
```

If the direct URL lands on the sign-in page, sign in first, then open the URL
again.

## Find Your Metrics

Your Python scripts send the metric:

```text
workshop.api.latency
```

Every datapoint includes a `participant_id` dimension. That dimension is the
string assigned to you by workshop staff, such as:

```text
participant-042
```

Look for your `participant_id` in these dashboard charts:

- **Fleet latency by participant**
- **Request volume by participant**
- **Apdex by participant**

Metrics can take a minute or two to appear. If you do not see your
`participant_id`, confirm that your Python setup check passed and that your
Replit Secrets or `.env` file use the exact assigned `PARTICIPANT_ID`.

## Token Values

Your Python environment needs these values:

- `SPLUNK_REALM` is `us1`
- `SPLUNK_INGEST_TOKEN` is the workshop ingest token value with `INGEST`
  authorization scope
- `SPLUNK_API_TOKEN` is the workshop API token value with `API` authorization
  scope
- `PARTICIPANT_ID` is your unique workshop alias from the handout

To copy the token values:

1. In Splunk Observability Cloud, open **Settings**.
2. Open **Access Tokens**.
3. Find the workshop **Ingest Token** and copy its token value into
   `SPLUNK_INGEST_TOKEN`.
4. Find the workshop **API Token** and copy its token value into
   `SPLUNK_API_TOKEN`.

Use token values/secrets, not token IDs. Token IDs identify tokens inside O11y;
Python needs the token values to authenticate. If the UI shows masked values,
use the **Copy** control for the token value rather than typing the masked
preview.

The ingest token and API token are different values. If you use the ingest token
for both fields, sending metrics can work while SignalFlow queries fail with an
unauthorized error.
