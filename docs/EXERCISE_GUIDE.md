# SignalFlow 101 Exercise Guide

Choose one path and stay in that file for the whole workshop. Each guide includes
setup, Splunk Observability Cloud token lookup, Exercise 1, Exercise 2,
Exercise 3, and the take-home exercises for that environment.

- [Replit path](EXERCISES_REPLIT.md) — recommended in-room path.
- [Splunk Show SSH path](EXERCISES_SPLUNK_SHOW.md) — use this if Replit is blocked.
- [Local Python path](EXERCISES_LOCAL.md) — use this only if Python was already working on your laptop before the workshop.

Do not try to merge instructions across files. Pick the one environment you are
using and keep reading that guide.
